# Research Portfolio -- Code Showcase

This repository contains selected code and replication scripts developed
by **Sagarika Sengupta** to showcase my quantitative research skills and
technical expertise.

The materials are shared for **viewing and professional evaluation
purposes**, including by prospective employers, academic institutions,
research collaborators, and fellowship selection committees.

They demonstrate my experience with statistical programming, data
management, econometric analysis, and research workflows using Stata, R,
and Python.
